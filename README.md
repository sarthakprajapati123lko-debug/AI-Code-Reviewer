# AI Code Reviewer 🔍

An automated Python static analysis utility designed to inspect code files for formatting standards, debug artifacts, and best practice improvements.

## Features ✨
- **Line Length Inspection:** Flags lines exceeding recommended standard lengths.
- **Debug Cleanup:** Highlights residual print statements before production release.
- **Docstring Audit:** Suggests documentation additions for functions.
